# CubeSolve Coach Web

MVP web interattivo del progetto CubeSolve Coach.

## Avvio locale

```powershell
pnpm install
pnpm run dev
```

## Verifica della build

```powershell
pnpm run build
```

## Funzioni attuali

- parsing della notazione 3x3;
- Cross configurabile per colore;
- scramble ricostruito;
- replay virtuale con controlli manuali e automatici;
- stato CFOP aggiornato dopo ogni mossa;
- timeline navigabile;
- layout responsive per computer e smartphone.

I video e gli altri dati personali non vengono caricati o inclusi nel sito.
